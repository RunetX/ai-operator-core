# Патч конфигурации для канала «бот в обсуждениях 1С»

Боты Системы взаимодействия до платформы 8.5.5 бывают только в конфигурации, а событие подбора пользователей расширение получает только как дополнение обработчика конфигурации. Поэтому каналу нужны в конфигурации две вещи. Логики в них нет, вся она в расширении `ИИОператор_Бот`:

- бот `ИИОператор` (`Bots/`): модуль бота передаёт сообщение в `ИИОБ_Бот.ОбработатьСообщение`, а без расширения ничего не делает;
- пустой обработчик `АвтоПодборПользователейСистемыВзаимодействия` в модуле управляемого приложения (`ManagedApplicationModule.insert.bsl`): к нему расширение добавляет свой через `&После`.

Если в конфигурации нет обработчика `ПриНажатииКнопкиПанелиКнопокСообщенияСистемыВзаимодействия`, его тоже нужно добавить пустым. В УТ 11.5 он есть.

## Установка

Нужны платформа 8.3.25 или новее и режим совместимости конфигурации не ниже 8.3.25. Конфигурацию должно быть можно менять: снятую с поддержки или на поддержке с разрешёнными изменениями.

```powershell
./tools/install-bot-cfg.ps1 -InfoBase 'C:\Bases\Trade' -User 'Администратор'          # файловая база
./tools/install-bot-cfg.ps1 -Server 'srv1c\trade' -User 'Администратор'               # серверная база
./tools/install-bot-cfg.ps1 -InfoBase 'C:\Bases\Trade' -User 'Администратор' -Check   # только проверить
```

Скрипт выгружает из базы корень конфигурации, дописывает бота и обработчик, если их нет, и загружает изменения частично. Новый бот требует монопольного доступа: закройте все сеансы базы, у серверной базы заблокируйте начало сеансов. После обновления типовой конфигурации патч накладывается заново тем же скриптом.

Дальше по [инструкции по развёртыванию](../../docs/install.md#7-бот-в-обсуждениях-1с): расширение `ИИОператор_Бот`, модель и регистрация базы в сервисе взаимодействия.
