# Быстрый старт за 15 минут

Для тех, кто прочитал статью и хочет попробовать сам. Путь: копия базы → установочная обработка → токен → MCP-клиент → первый вопрос. Подробности и ручная установка — в [install.md](install.md), настройка клиентов — в [clients.md](clients.md).

## Что понадобится

| Что | Версия | Заметки |
|---|---|---|
| Платформа 1С | 8.3.20 или новее, тонкий клиент Windows x64 или x86 | Веб-клиент, Linux и macOS не подойдут: MCP-сервер собран только для Windows |
| Конфигурация | БСП 3.1: «Бухгалтерия предприятия 3.0», «Зарплата и управление персоналом 3.1», «Управление торговлей 11.5» | Режим совместимости не ниже 8.3.20. Для других конфигураций на БСП — установка из исходников, [install.md](install.md#2-установка-в-базу) |
| Ядро ИИ-оператора | 0.1.16.0 | Ставит установочная обработка |
| MCP-клиент | Claude Code, Claude Desktop или LM Studio | Для Claude Desktop и LM Studio ещё Node.js: `winget install OpenJS.NodeJS.LTS` |
| Доступ в интернет с сервера 1С | `github.com` | Обработка скачивает расширения из Releases. Прокси — из настроек интернет-поддержки |

По желанию:

| Что | Версия | Что нужно в базе |
|---|---|---|
| Бот в обсуждениях 1С | 0.1.1.1 | Платформа и режим совместимости не ниже 8.3.25, патч конфигурации, база в Системе взаимодействия, модель с OpenAI-совместимым API. Установка — [раздел 6](install.md#6-бот-в-обсуждениях-1с) |
| [Пакет КЭДО](https://github.com/RunetX/ai-operator-kedo) | 0.2.1.0 | ЗУП 3.1 и расширение Контур.КЭДО 1.26 или новее |
| [Пакет ЭТрН](https://github.com/RunetX/ai-operator-epd) | 0.1.1.0 | БП 3.0 или УТ 11.5 с электронными транспортными накладными в библиотеке ЭДО (проверено на БЭД 1.9.16) |

Пакеты обработка предлагает сама, если они подходят базе. Совместимые версии она выбирает по `manifest.json` релизов.

## Установка

Пробуйте на копии базы: демо-база или резервная копия рабочей.

1. **Обработка** (около 3 минут). Скачайте `ai-operator-installer-0.1.16.0.epf` из [Releases](https://github.com/RunetX/ai-operator-core/releases). Откройте базу под администратором, чтобы в ней никто не работал.
   - На копии базы БСП при входе спросит, перемещена ли база: ответьте «Это копия информационной базы». Остальные стартовые окна демо-базы закройте: путеводитель, интернет-поддержку, «Рекомендуется обновить версию» («Напомнить позже»).
   - «Файл → Открыть», выберите обработку. Все строки проверок вверху должны быть «Ок». Подходящие базе пакеты обработка отмечает сама: в БП 3.0 это ядро и пакет ЭТрН. Лишний пакет можно снять.
   - Нажмите «Установить» и ответьте «Да» на предупреждение об источнике расширений.
   - Когда появится кнопка «Перезапустить», нажмите её, а на вопрос «Завершить работу с приложением?» — «Завершить работу». 1С откроется с формой «Состояние ИИ-оператора».
2. **Компонента.** В форме «Состояние» дважды щёлкните строку «Компонента MCP-транспорта» или выберите «ИИ-оператор → Запустить ИИ-оператор». 1С предложит установить компоненту — согласитесь, затем в окне «Внешняя компонента успешно установлена» нажмите «OK». Это один раз на компьютер. Следом 1С скажет, что ИИ-оператор не запущен: нет токена. Так и должно быть: токен — следующий шаг.
3. **Токен и запуск.** Дважды щёлкните строку «Токен доступа» — токен создаётся сразу. Затем дважды щёлкните строку «MCP-сервер в этом сеансе» или снова выберите «ИИ-оператор → Запустить ИИ-оператор». Итог формы — «Ошибок: 0». Предупреждения «Разрешенные действия» и «Модель маскирования» для первого знакомства не мешают.
4. **Клиент.**
   - Claude Code: кнопка «Настройки для Claude Code» показывает готовый `.mcp.json`. Скопируйте текст от первой `{` до конца, сохраните в файл `.mcp.json` в каталоге проекта и запустите `claude` из этого каталога. При первом запуске Claude Code спросит, доверять ли каталогу и подключать ли сервер `onec` из `.mcp.json`: ответьте «да».
   - Claude Desktop или LM Studio: кнопка «Настройки для Claude Desktop и LM Studio» показывает запись для конфигурации клиента. Вставьте её и перезапустите клиент.
5. **Проверка.** Попросите в клиенте: «Проверь связь с 1С». Модель назовёт версию ИИ-оператора, конфигурацию и платформу.

**Действия.** Проводить и отменять проведение агент сможет только по разрешению: раздел «ИИ-оператор» → «Разрешения действий ИИ-оператора», запись на пользователя или группу. Без неё агент только читает и показывает.

## Что спросить

Вопросы из статей на Инфостарте. Даты и контрагенты — из демо-базы БП 3.0.

**[ИИ-агент проводит документы, но кнопку «Выполнить» нажимаете вы](https://infostart.ru/1c/articles/2800981/)** — ядро в БП:
- «Покажи реализации Суприма за февраль 2016». Агент переспросит, какой из «Супримов», и откроет список реализаций с отбором.
- «Какая выручка от Суприм-Тверь за 1 квартал 2016?». Откроется отчёт «Продажи по контрагентам» с тем же периодом и отбором.
- «Отмени проведение реализаций Бар Дионис за ноябрь 2016». Откроется предпросмотр, «Выполнить» нажимаете вы. Нужно разрешение действия.
- «Какие контрагенты — физлица? Назови их ИНН и телефоны». Модель видит `[ФИО#1]`, а список с настоящими именами открывается в 1С.

**[Кто распровёл квартал: журнал, откат и кнопка, которую жмёт человек](https://infostart.ru/1c/articles/2811615/)** — ядро в БП:
- «Проведи их», затем «Отмени то, что сейчас провёл». Агент откатит ровно свой пакет.
- Раздел «ИИ-оператор» → «Журнал операций ИИ-оператора»: пакеты, документы и кнопка «Откатить пакет».
- «Журнал обмена с моделью»: что ушло модели и что было скрыто.

**[Из Иванова приехали две фуры](https://infostart.ru/1c/articles/2807944/)** — маскирование персональных данных:
- «Что видит нейросеть» → «Проверить фразу»: введите «Водитель Сидоров говорит, что груз сдал» и посмотрите, что получит модель.
- Вопросы боту в обсуждении документа маскируются целиком, вместе с вопросом. Для этого нужен бот и, для людей не из базы, локальная модель маскирования — [раздел 6](install.md#6-бот-в-обсуждениях-1с).

**[ИИ-оператор управляет КЭДО](https://infostart.ru/1c/articles/2806328/)** — ядро и пакет КЭДО в ЗУП:
- «Что сейчас не так с КЭДО в нашей организации?» — сводка в чате.
- «Кто из принятых в сентябре ещё не подключён к КЭДО? Покажи их» — список сотрудников в 1С.
- «Пригласи тех, у кого есть почта» — откроется штатная форма приглашения КЭДО, «Пригласить» нажимаете вы. Нужно разрешение действия `kedo_invite`.

## LM Studio

LM Studio бывает двумя вещами:
- **MCP-клиентом** с локальной моделью. Подключается мостом из формы «Состояние», как Claude Desktop.
- **Моделью бота.** В «Настройках ИИ-оператора», группа «Модель», укажите адрес `http://<компьютер>:1234/v1` и имя модели, например `google/gemma-4-26b-a4b`.

Чтобы модель отвечала быстро и не теряла контекст:
- контекст 32k, одновременных предсказаний 1;
- для моделей из экспертов (Gemma 4 26B-A4B) — веса экспертов на процессор;
- в системный промпт беседы вставьте раздел `## instructions` из макета описаний: LM Studio не передаёт его модели сам.

Подробнее — [clients.md](clients.md#lm-studio-локальная-модель).
